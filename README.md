# E-commerce Frontend

A React and Vite e-commerce application with customer and admin pages.

## Pages and Routes

### Customer pages

| Page | Route |
|---|---|
| Home | `/` |
| Products | `/products` |
| Product details | `/products/:id` |
| Login | `/login` |
| Register | `/register` |
| Wishlist | `/wishlist` |
| Cart | `/cart` |
| Checkout | `/checkout` |
| My orders | `/orders` |

### Admin pages

| Page | Route |
|---|---|
| Admin dashboard | `/admin` |
| Manage products | `/admin/products` |
| All products | `/admin/products/all` |
| Manage orders | `/admin/orders` |
| Manage users | `/admin/all/users` |

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Validation

```bash
npm run lint
npm run build
```
